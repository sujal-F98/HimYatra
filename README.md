# HimVelly Journeys 🏔️
### Curated Himachal & Uttarakhand Travel Experiences & Eco Chalets

A complete, interactive, mobile-responsive web platform for a Himachal-based travel and tour business specializing in curated tour packages, boutique wooden stays, and custom Himalayan road trips across Himachal Pradesh and Uttarakhand.

---

## 🌟 Key Features

* **Woodvelly-Inspired Design**: Dark atmospheric hero section featuring misty pine forests, illuminated mountain chalets, and a floating frosted-glass reservation widget.
* **Destinations Explorer**: Filterable by *Himachal Pradesh* (Manali, Spiti, Kasol, Jibhi, Shimla, Dharamshala), *Uttarakhand* (Auli, Chopta, Kedarnath, Rishikesh, Mussoorie, Nainital), *Snow & High Altitude*, and *Sacred & Spiritual* with real-time search.
* **Tour Packages & Day-by-Day Itineraries**: Interactive modals with morning/afternoon/evening breakdowns, route overviews, inclusions/exclusions checklists, and live cost calculation.
* **The Woodvelly Collection**: Handpicked wooden chalets and eco-resorts (*Novem Natural Eco Resort*, *Woodvelly Pine Ridge Chalets*, *The Whispering Pines*, etc.).
* **Custom Tour Planner Engine**: Multi-step itinerary customizer with dynamic real-time price estimation based on travelers, days, vehicle type, and stay tier.
* **Seasonal Snow & Weather Guide**: Interactive guide for Winter Snow (Dec-Feb), Spring Blossoms (Mar-Apr), Summer Escapes (May-Jun), and Golden Autumn (Sep-Nov).
* **Supabase Cloud Backend**: Connected to Supabase PostgreSQL database storing real-time leads, bookings, custom trip plans, inquiries, and newsletter subscribers.
* **WhatsApp & Direct Call Integration**: One-click WhatsApp chats with pre-filled itineraries to `+91 94798 17027`.

## 🚀 Tech Stack

* **Frontend**: React 18, Vite.js
* **Styling**: Tailwind CSS, PostCSS, Custom Glassmorphism
* **Icons**: Lucide React
* **Backend**: Supabase (PostgreSQL, Row Level Security, REST Data API)
* **Hosting / Runtime**: Node.js v22

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/akshatghatiya3-ui/HimYatra.git
cd HimYatra
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory (or use `.env.example`):
```env
VITE_SUPABASE_URL=https://ueojgkifvxrkfugwlotm.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
```

### 4. Run Development Server
```bash
npm run dev
```

### 5. Build for Production
```bash
npm run build
```
